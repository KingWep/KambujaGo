# KambujaGo

KambujaGo is a React application built with Vite and plain JavaScript.

## Development

```bash
npm install
npm run dev
```

The project uses `.jsx` for React components and `.js` for JavaScript modules.

## Project structure

- `src/components`: reusable presentation primitives and layout components
- `src/features`: travel-domain behavior grouped by feature
- `src/services`: shared API and currency services
- `src/hooks`: reusable React hooks
- `src/constants`: application configuration and route data
- `src/utils`: pure utility functions
